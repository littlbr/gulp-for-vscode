# Projets de démonstration

Deux projets fictifs pour tester l'extension et produire les captures du README, sans données réelles.

```bash
cd demo/atelier-lumen && npm install
cd ../boutique-nova && npm install
code demo/demo.code-workspace
```

Les tâches ne font que simuler un build (délais et journaux) : aucune dépendance autre que Gulp.
